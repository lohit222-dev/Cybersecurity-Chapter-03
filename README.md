# Chapter 3: Cybercrimes & Cybersecurity — Interactive Web Portal

An interactive study portal covering **Chapter 3: Cybercrimes and Cybersecurity — The Legal Perspectives & Organizational Implications**.

## ✨ Features
- **Interactive Modules (`3.1` – `3.11`):** Global Cyber Law Explorer, Indian IT Act (2000 & 2008) Penalty Finder, Live PKI Digital Signature Simulator, IPR Case Explorer, SQLi vs. XSS Lab, and 6-Stage CSIRT Incident Playbook.
- **Visual Diagram Gallery:** 11 high-resolution infographics with fullscreen lightbox zoom.
- **Active Recall & Assessment:** 16 3D Flip Flashcards & a 10-question Self-Assessment Quiz with instant explanations.
- **Solved University Exam Bank:** Complete, structured solutions to all 9 Chapter Review Questions (`1A`, `1C`, `2A`, `2B`, `3A`, `4C`, `6A`, `7A`, `7B`).
- **Downloadable Study Guide:** Includes `Chapter_3_Cybercrimes_and_Cybersecurity_Interactive_Edition.docx`.

## 🚀 Run Locally
```bash
python server.py
```
Then open `http://localhost:8080` in your browser.
